# Brick Rigs Server Director

Overview:  
Brick Rigs Server Director is an injected mod for brick rigs that adds various administrative and creative additions to help manage your brick rigs server.

### BRSD is currently in alpha!

## Working On
 - Blackist
 - Saver
 - Anti Cheat

## Currently Developed Features
 - Command Engine customizability
 - Simple logging (things like last player joined)
 - Basic moderation menu
 - Additional commands

## Planning:

### Added Commands:
 - kill [who] - kills a player
 - revive [who] - revives a player
 - empty [who] - clears a players inventory
 - vehdel [who] - deletes vehicles spawned by that player
 - saver [name] - runs the saver module and saves the vehicle states 
 - loader [name] - loads the saved vehicle states based on name

### Spectator Mode:
 Added mode/toggle to force spectator mode even in non-abiding game modes.

### Blacklist Features:
 - Blacklisted Steam Links
 - Blacklisted Bricks
 - Blacklisted Vehicle Name Keywords

### Saver Menu Features:
Save all vehicle states (vehicle, location, rotation, scale)
Load saved vehicle states.
List and manage vehicle states including renames.
Xml or json depending on the easier one to use.

### Logging Features:

History of when players spawn vehicles
History of when players join and leave
